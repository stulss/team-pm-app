# 프로젝트 목표

> 목표를 바꿀 때는 맨 아래 **변경 이력**에 바꾼 이유를 한 줄 남긴다.

## 한 줄 소개

2~10명 규모의 원격 팀이 프로젝트와 작업을 칸반 보드로 함께 관리하는 웹앱.

## 누구를 위한 것인가

떨어져서 일하는 2~10명의 소규모 팀. 팀장(Manager)이 프로젝트를 만들고 팀원을 배정하며, 팀원(Member)이 작업을 처리한다. 별도 도구 없이 한곳에서 진행 상황을 보고 싶은 팀이 대상이다.

## 핵심 기능 3가지

1. **프로젝트·작업 관리** — 로그인과 역할(Admin/Manager/Member), 프로젝트·멤버 관리, 작업 생성·배정·마감일·우선순위
2. **칸반 보드 + 실시간 동기화** — 드래그로 상태 이동(todo → in_progress → review → done), 팀원 화면에 1초 내 반영
3. **댓글·알림** — 작업별 댓글, 배정·마감 임박 알림

대시보드(진행률·지연 작업)는 최종본 단계에서 추가한다.

## 범위 밖 (다음 버전)

초대 링크, 이메일 알림, 파일 첨부, 서브태스크/라벨, 커스텀 칸반 컬럼, @멘션 알림, 다중 팀(워크스페이스), 다국어. 자세한 목록은 `DESIGN.md` §6.

## 완성의 기준

**팀원 3명이 배포된 URL에서 일주일간 실제 프로젝트 하나를 이 앱으로 운영한다.**

- [ ] 가입 → 로그인 → 새로고침 후에도 세션 유지
- [ ] 프로젝트 생성과 멤버 초대, 비멤버 접근 시 403
- [ ] 두 브라우저에서 칸반 이동이 1초 내 반영
- [ ] 작업 배정 시 알림이 즉시 도착
- [ ] 핵심 흐름 E2E 테스트 통과

> 미정: 실제 사용할 팀원 3명이 확정되지 않았다면 "역할별 테스트 계정 3개로 시나리오 통과"로 기준을 낮춘다.

## 단계별 목표

| 단계 | 목표 |
|---|---|
| 1차 중간점검 | 배포된 URL에서 가입 → 프로젝트 생성 → 작업 CRUD |
| 2차 중간점검 | 칸반·실시간·댓글까지 MVP 완성 |
| 최종본 | 알림·대시보드·보안·테스트, 프로덕션 배포 |

상세 일정과 체크리스트는 [ROADMAP.md](ROADMAP.md).
